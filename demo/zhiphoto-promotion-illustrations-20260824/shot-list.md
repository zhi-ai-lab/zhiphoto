# ZhiPhoto promotion illustration shot list

Six standalone 16:9 article illustrations, generated in order with the attached Jas IP template as the recurring character reference.

1. **Idea to image — the prompt workbench**

   Structure: conceptual metaphor. Jas IP turns a rough floating idea card through a hand-drawn prompt workbench into a clean image card, physically tightening a loose coil of orange thread as the idea becomes visual.

2. **Text to image — the paper-to-picture press**

   Structure: workflow. Jas IP feeds a short text strip into a strange tabletop press; on the right, the press outputs one framed illustration, with a single orange path connecting language to picture.

3. **Control style and composition — the visual mixing desk**

   Structure: system slice. Jas IP operates two large physical dials labelled “style” and “composition” on a sparse sketching machine, aligning a small subject block and a color swatch into a deliberate frame.

4. **Iterate toward a better result — the feedback loop**

   Structure: state change. Jas IP pulls a circular orange loop through three compact stages—draft, inspect, refine—while red correction marks on the first pass become a clean resolved image on the last pass.

5. **Put the output into content — the content mailbox**

   Structure: route map. Jas IP carries a verified image card along a curved orange path from an export tray into three quiet destinations: article, post, and brand shelf; the action is handoff, not a collage.

6. **Multiple style-template collections — the reusable template cabinet**

   Structure: layered method. Jas IP sorts a few distinct style cards into a tall open cabinet of reusable collections, then pulls one card to the front to show that the catalog expands without losing structure.

## Shared visual direction

- Standalone 16:9 horizontal images; never a collage or contact sheet.
- Pure white background, sparse hand-drawn line art, generous blank space.
- Use the attached Jas IP template only for recurring identity; do not reproduce its character-sheet layout or labels.
- Preserve the template’s black hoodie, glasses, beard, proportions, and palette; use orange for flow, red only for warnings/corrections, and blue only for secondary system state.
- English labels only when necessary; keep them short and handwritten.
