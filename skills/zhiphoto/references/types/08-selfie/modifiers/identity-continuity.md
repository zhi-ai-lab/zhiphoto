# Identity Continuity Modifier

Use this modifier only when the user provides a reference image or asks for the same fictional or previously established adult person across images.

- Treat stable facial structure, skin tone, hairline, eye spacing, nose, lips, distinctive marks, and approximate apparent age as identity anchors.
- Preserve those anchors across changes in expression, makeup, hair styling, wardrobe, camera angle, and lighting.
- Describe only visible traits needed for continuity. Do not infer identity, ethnicity, health, personality, or other sensitive facts from an image.
- Allow scene lighting and lens perspective to change appearance naturally; do not flatten the face into an identical cutout.
- If the reference person's age is ambiguous and the requested scene is sexualized or sensual, do not use the reference until the subject is established as an adult. Use an unmistakably adult fictional subject instead when appropriate.
