# Composition Patterns and Originality Rules

## Core Structure Families

Choose one structure family per image. Do not mix too many.

### Workflow

Best for input -> process -> output, content production, AI workflows, and automation chains.

Composition: input on the left, processing in the middle, output on the right, with orange arrows carrying the main flow. The recurring character or a strange machine should perform the key action.

### System Slice

Best for information sources, filters, databases, renderers, or one meaningful part of an agent system.

Composition: show only 3-5 core modules. The recurring character should operate one important step.

### Before / After

Best for chaos vs. order, manual vs. automated, scattered vs. consolidated, anxious vs. stable.

Composition: unstable state on the left, resolved state on the right, orange transition between them. The character can exaggerate the contrast through its action.

### State Change

Best for user pain points, creator states, tool overload, information anxiety, or moving from stuck to moving.

Composition: 2-4 compact states, each with a short note.

### Conceptual Metaphor

Best for a content factory, information warehouse, black-box mind, workflow machine, or automated digest.

Composition: one large strange object or machine, limited inputs, one output, and a memorable action.

### Layered Method

Best for frameworks, system layers, capability stacks, or a content-system hierarchy.

Composition: stacked boxes or built-up layers rather than a formal pyramid. The recurring character should build, carry, or repair part of the stack.

### Route Map

Best for journeys from idea to launch, user paths, content handoff routes, or learning paths.

Composition: one curving path with a few nodes. The character should pull, walk, connect, or guide the route.

### Small Comic Beat

Best for failure-to-success transitions, true process moments, commentary, or before/after behavior.

Composition: 2-4 small scenes, one action per scene.

## How to Invent a Fresh Metaphor

Reinvent the metaphor from the current article every time. Do not copy an old image.

### Three-step method

1. Convert the abstract concept into a physical action: jammed, leaking, getting heavier, sorting, settling, fermenting, opening, folding, unpacking, looping back.
2. Convert the system structure into a low-tech object: a broken machine, paper box, drawer, pipe, mailbox, strange gauge, scale, well, ladder, or odd workstation.
3. Make the recurring character do the work: stuck in the machine, pulling the wrong wire, guarding a gate, carrying, repairing, weighing, holding a ladder, recording, or feeding something into a weird device.

### Object pool

- Paper box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, cable tangle, gate, turntable, black box, puncher, press, clothesline, odd workstation.
- Choose only 1-2 objects per image.

### Action pool

- Pull, carry, stuff, scoop, press, weigh, stitch, cut, twist, guard, push, connect, unpack, mark, recycle.
- The action must serve the core idea.

## No direct reuse

Do not default to opening or recreating any old examples. Prior examples are only useful for calibrating line density, whitespace, palette restraint, and the deadpan character attitude.

Unless the customer explicitly asks to copy a previous composition, do not directly reuse a known layout. Even for a similar theme, invent a new main object and a new recurring-character action.
