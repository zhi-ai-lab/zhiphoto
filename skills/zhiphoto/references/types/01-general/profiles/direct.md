# Direct Brief

## Use When

No specialized type or profile materially improves the request.

## Profile Deltas

- Preserve the user's wording and specificity while organizing it into a coherent visual brief.
- Add only restrained connective detail needed to make the requested subject, environment, lighting, and composition work together.

## Profile-Specific Avoidances

- Avoid importing conventions from an unrelated image category.
- Avoid replacing a concise request with generic cinematic, photorealistic, or highly detailed styling unless requested.
