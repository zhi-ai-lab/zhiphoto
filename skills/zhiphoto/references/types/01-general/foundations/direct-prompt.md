# Direct Prompt Foundation

Turn the user's request into one coherent, generation-ready image prompt.

- Keep the requested subject, action, environment, medium, style, mood, lighting, camera or viewpoint, composition, text, colors, and aspect ratio authoritative.
- Resolve small unstated details conservatively when they are needed for coherence. Ask only when a missing choice would materially change the deliverable.
- Use concrete visual language and causal lighting or spatial relationships. Avoid generic quality-token lists and unrequested stylistic embellishment.
- End with only the likely failure modes for this image. Do not add browser steps, export instructions, local paths, or private provenance to the prompt.
