# Big Type Cover

## Use When

Use when the sentence can be compressed into a very short punchline that big type alone can carry, including when the sentence encodes a before/after change worth showing as two states. This is the default profile when both layouts fit equally.

## Profile Deltas

- Before drawing, decide whether the sentence is a **before/after change**, a **finished result**, or a **single outcome**, and compose from that reading.
- Main line: the shortest sentence that still makes sense at a glance — 1 line preferred, 2 lines max. Never a long method sentence.
- Big type takes the frame.
- Audience line: about one-third the main line size, and it can be very small.
- Method line: a 4–8 character tag sitting in a corner; it must not compete with the main line.
- Draw the character twice only if the sentence itself has two states; otherwise draw the character once.

## Profile-Specific Avoidances

- Do not default to an arrow.
- Do not default to a left-right split.
- No extra paragraphs beyond the three copy lines.
