# Title + Illustration Cover

## Use When

Use when the conclusion needs a complete, easy-to-read sentence rather than a compressed punchline, or when the cover should lean on a clear illustration of the character acting the line — especially when a big-type-only layout would fragment the sentence into stacked pieces.

## Profile Deltas

- Main line: one complete, easy-to-read conclusion — 1–2 lines, readable as a whole.
- The character acts the line with expression and pose. Show the character once, or once on each side with empty space around them.
- Layout: big title + one clear illustration + one method tag. Keep whitespace.
- Audience line: whose situation this is, one sentence, about one-third the main line size.
- Add as little extra text as possible beyond the three copy lines and the character.

## Profile-Specific Avoidances

- Do not stack modules or break the main line into stacked fragments.
- No card groups on both sides of the frame.
- No footer timeline, no multi-cell process row.
